# Как пользоваться Пультом

[README](../README.ru.md) · [Установка](install.ru.md) · **Как пользоваться** · [Если что-то не так](troubleshooting.ru.md) · [English](usage.md)

Пульт — приложение внутри Telegram для ИИ-агентов на твоём компьютере: приложение — главный экран, чат зовёт, когда
нужен ты. Там видна каждая сессия Claude Code — вкладки VS Code, терминалы, задачи, которые ты запускаешь с телефона, —
на моделях Claude или другого производителя, а сделанное одной моделью может проверить другая.

## В приложении

- **«Главная»** построена вокруг того, чей ход: что идёт сейчас (у каждой задачи — твой запрос и что Claude пишет
  прямо сейчас), ниже — что ждёт тебя: запросы разрешений с ответом прямо там и каждая закончившая сессия, с готовыми
  ответами из сообщения самого Claude, — и все проекты, каждый своим цветом. Законченная задача, даже простой отчёт,
  остаётся там, пока ты не нажмёшь **«Проверено»** (на карточке или под итогом в сессии) или не ответишь: открыть её —
  не значит убрать, так ничего законченного не проскочит непроверенным. Что решает касание, можно отменить: вариант
  вопроса, **«Разрешить»** и **«Отклонить»** уходят через три секунды, рядом **«Отменить»**; **«Проверено»** оставляет
  внизу записку — **«Вернуть»** — на пять секунд; **«Стоп»** спрашивает, прежде чем остановить ход. Под **«Разрешать
  всегда»** карточка говорит, что именно станет разрешено и где: «команды `npm test …` — в этом проекте, насовсем»,
  «правку файлов без вопроса — до конца задачи». У каждого состояния свой цвет: что идёт —
  зелёное, что ждёт тебя — тёплое, вся карточка (упавшая — красноватая), история — без цвета, у каждой строки серая
  галочка проверенной тобой задачи; на экране проекта — так же.
- **Закреплённые проекты**: сдвинь строку проекта влево на экране «Проекты» и нажми «Закрепить» — или кнопку с
  булавкой в шапке проекта. Закреплённые стоят сверху в «Проектах», на «Главной» и в списке новой задачи, новый — выше;
  остальные — как прежде, по тому, кому нужен ты. Закрепление хранит компьютер: на любом телефоне одно и то же.
  Под тем же сдвигом — **«Скрыть»**: проект уходит в свёрнутые «Скрытые» внизу «Проектов», с «Главной» и из списка новой
  задачи пропадает (что в нём идёт и что ждёт тебя, видно по-прежнему; сдвиг в «Скрытых» возвращает), — и **«Новая задача»**,
  сразу форма с этим проектом. Строка задачи сдвигается к **«Тегам»**, карточка «Твой ход» — к **«Проверено»**; вопросы и
  разрешения не сдвигаются.
- **Скопировать сообщение**: в сессии сдвинь его влево, пока не загорится значок копирования, и отпусти. Сообщение
  Claude целиком уходит в буфер с форматированием, как копирует сам Telegram, — вставка в Telegram, заметки или почту
  сохранит жирный, ссылки, код и цитаты, — и markdown Claude для мест, где только простой текст; твоё — как ты его
  написал. Нажатие на серый блок кода по-прежнему копирует только этот блок.
- **Сессия** — вся переписка вживую; у поля ввода — модель, раздумья и шкала контекста. Выбери модель и насколько
  глубоко Claude думает в этой сессии; идущая переключается сразу. У моделей — версии, какие им даёт Claude Code этой
  сессии: «Fable 5.2», «Opus 5.5», — поэтому вкладка VS Code на старой Claude Code может сказать «Fable 5.1»; **Другие
  версии** под меню оставляют сессию на прежней, как собственное меню Claude Code. «Настройки → Модели и ключи → Модель и
  раздумья» — с чем начинаются сессии из приложения и Telegram; вкладки VS Code — по своим настройкам.
- **Теги**: у каждой задачи два — раздел проекта и подраздел в нём; их ставит та же маленькая модель, что пишет строку
  итога, сразу по запросу и ещё раз в конце хода. Модель включается переключателем «Настройки → Модели и ключи → Итог одной строкой и
  теги» (сначала он выключен). Папки и файлы — только подсказка ей: больше настраивать ничего не нужно. Нажми раздел
  наверху экрана проекта — останутся только его задачи (и ряд его подразделов); нажми теги под заголовком задачи — поправишь,
  и твой выбор останется. `#тег` в тексте запроса ставит его сразу — даже когда переключатель выключен. В Telegram итог
  хода заканчивается ими же — хештегами: `#прошивка #датчик_филамента`, нажмёшь — все сообщения с ним («Настройки →
  Уведомления → Хештеги в Telegram»). Значок тега рядом с разделами проекта открывает все его теги — самые ходовые наверху, у
  каждого число задач: переименовать раздел или подраздел, дать разделу цвет, слить два в один, скрыть (у задач тег
  остаётся, но в строках, фильтре и Telegram его не видно; вернуть — внизу экрана). Тег, который Claude только что
  придумал, обведён пунктиром, пока ты его не оставишь или не сольёшь с другим. Claude и сам просматривает список и
  предлагает слить два тега об одном и том же; «Оставить обе» — больше не предложит. Дальше Claude ставит твои
  названия: старое имя, если он его принесёт, ляжет на новый тег. Когда переключатель включён, при первом открытии
  проекта Claude сам раскладывает его прежние задачи без тегов (последние 200, по двадцать, в фоне; под разделами —
  «Claude раскладывает прежние задачи: 40 из 120») — один раз на проект. «Разложить заново» внизу экрана тегов сначала
  спросит, потом составит список с нуля — из README, CLAUDE.md, последних задач и твоих тегов — и разложит по нему все
  задачи, кроме тех, где тег ставил ты; около минуты. Каждый тег, который ты ставишь сам — в листе задачи, `#тегом`,
  слиянием, — пример для Claude: он видит шесть последних в проекте и так же раскладывает похожие задачи; «Claude ставит
  сам» в листе забирает пример обратно.
- **Верх «Главной»**: лимит, который кончится первым, — своей плашкой, и машина, где работает Пульт, — процессор,
  память и у ноутбука питание: вилка или батарейка с зарядом, жёлтая с 20 %, красная с 10 %. От батареи Пульт пишет в
  «Общую» на 20 % и со звуком в любом режиме на 10 % — на последних процентах машина уснёт и ходы на ней оборвутся;
  подключил зарядку после предупреждения — тихое «зарядка подключена».
- **«Ресурсы»**: «Лимиты» — кривая каждого лимита против ровного темпа, прогноз (в темпе; недобор — сколько часов
  работы сессии сгорит; перебор — когда кончится), кто съел; вкладка машины — по её имени («MacBook Air», «homelab» —
  ноутбук или сервер; переименовать — «Настройки → Пульт и его части»): процессор, память, у ноутбука питание (заряд,
  оценка системы, циклы и ёмкость от новой) и команды каждой сессии Claude.
  С 85 % памяти компьютера об этом говорит строка вверху любого экрана, с 95 % — красная; касание открывает «Ресурсы».
- **Файлы хода**: что Claude создал или изменил в проекте — отметь нужные и отправь в тему по одному или одним
  архивом; файлы прошлых ходов — в соседних.
- **Изменения**: под итогом задачи — **«Изменения: 4 файла +120 −30»** — что задача изменила в проекте, по git: от
  коммита, на котором папка стояла в начале задачи, — закоммиченное с тех пор и нет, новые файлы тоже. Касание
  открывает список своих файлов задачи — тех, что писали её инструменты и трогали её ходы; что ещё изменилось в папке
  за это время, командами или другими задачами, свёрнуто под ними. Файл открывает правку построчно: убранные строки с
  **−**, добавленные с **+**, между двумя кусками — сколько строк без правок; **«Весь файл»** показывает его целиком с
  правками на местах. Файлы, похожие на ключи и настройки, считаются, но не показываются. Это просмотр: отсюда ничего
  не коммитится и не меняется. У проекта не в git такой строки нет.
- **Новый проект**: папка где угодно в домашней — пустая с git, с `CLAUDE.md`, который Claude напишет по твоему
  описанию, или клон репозитория. Тема проекта сразу появляется в группе.

- **«Настройки»** — меню из пяти экранов: «Уведомления», «Модели и ключи», «Голос и язык», «Пульт и его части»,
  «Безопасность»; в каждой строке видно, что там стоит сейчас.
- **Сам Пульт**: «Настройки → Пульт и его части» — компьютер, приложение и посредник на твоём сервере, копия на этом
  телефоне, вкладки VS Code, хуки, Claude Code и выпуск: что у каждой стоит и насколько отстало от ветки, из которой
  Пульт поставлен. Новый выпуск ставится оттуда одной кнопкой (macOS, Linux; клон сам находит выпуски на GitHub), сервер
  приложения берёт тот же с GitHub ([один раз: `install.sh --auto`](../deploy/relay/README.md#updates)). Версию Claude
  Code, которую скачал VS Code, Пульт проверяет на компьютере до того, как на неё перейдут вкладки; выключатель —
  «Проверять новые версии Claude Code». Если на ней работает и сессия из приложения, новые и продолженные задачи из
  приложения запускаются на ней, а не на Claude Code, встроенном в Пульт, которого двигает только выпуск Пульта;
  выключатель — «Свежий Claude Code для приложения». Задачи на моделях других производителей и на своей остаются на
  встроенном. Там же видно, какой Claude Code вышел. Если перезапуск что-то оборвёт, в списке видно, что делает каждая
  задача и сколько: у хода — минуты, у фоновой команды — её имя; касание открывает задачу или лист её фоновых задач.
  «Поставить, когда освободятся» их ждёт; если держат одни фоновые 30 минут (и ещё раз через 2 часа), Пульт скажет об
  этом в «Общей», с кнопкой «Остановить и поставить».

## Кто делает задачу и кто проверяет

Пульт управляет родной программой каждого производителя: Claude Code — для моделей Claude и, внутри него, для
DeepSeek, GLM и Kimi и для своей модели через Ollama; Codex — для своих задач и для второго мнения. Поэтому одна модель
может сделать задачу, а другая — проверить, и всё это с телефона.

- **Проект — у одной модели**: Claude, Codex, DeepSeek, GLM, Kimi или своя модель — она делает все задачи проекта, из
  приложения и из Telegram. Экран проекта называет её под именем; шестерёнка открывает **«Настройки проекта»**, где она меняется — только
  когда в проекте ничего не идёт (ход, очередь, фоновая задача или помощник), и сначала сказав, куда уйдёт код. Задачи
  прежней модели остаются — только для чтения: открыть, прочитать, скопировать; продолжить — вернув проекту её модель.
  **«Кто делает»** в «Новой задаче» показывает модель проекта и ведёт в его настройки; поле модели — её собственные модели
  (и уровни раздумий Codex). DeepSeek, GLM и Kimi работают внутри Claude Code — они отвечают его же протоколом по своему
  адресу — по твоему ключу: ход, карточки, итог и тема — как с Claude. Ключ кладёшь в «Настройки → Модели и ключи» —
  он проверяется одним крошечным запросом и остаётся на компьютере, — там же его модели списком: галочка — модель есть
  в выборе задачи, звезда — основная, **«Помощники»** — модель, на которой работают подагенты; модель, которой нет в
  списке Пульта, добавляется по имени. «Настройки → Модели и ключи → **Модель новых проектов**» — её получает
  проект, созданный в приложении (в его форме можно выбрать другую). Модель без ключа или выключенная своя задачу
  проекта не возьмёт — и Claude вместо неё тоже. Сессия производителя в списке VS Code не видна. Anthropic этого не
  поддерживает, а подсказки Claude Code написаны под Claude: это для задач подешевле, не для сложных.
- **Настройки проекта**: кроме модели — **«Помощник Claude (haiku)»**, строка итога и теги: включён у проектов Claude,
  выключен у остальных (включённый отправляет запрос и итог задач в Anthropic — сначала спросит); **«Тема в Telegram»** —
  «Запрос и итог» или «Только „готово“»: слова задачи в Telegram не уходят, только «готово» и «ждёт тебя», файлы по
  `pult send` туда тоже не отправляются; **ревью** — второе мнение только по твоему касанию и разрешение Codex читать код,
  с **«Запретить»**; теги проекта, закрепить и спрятать. Вкладку VS Code или терминал с Claude в проекте другой модели
  Пульт замечает: тема услышит это один раз, экран проекта скажет.
- **Отдельно от Claude**: задача на модели другого производителя идёт в своём «доме» Claude Code (в папке Пульта): твой
  глобальный CLAUDE.md, настройки и память в её запросы не попадают, а её переписка и память — не в `~/.claude`; служебные
  запросы Claude Code наружу выключены, а модели сказано, кто она. Claude haiku читает такие задачи, только если включишь
  его в проекте, — иначе строка итога у них — первая фраза ответа, теги ставишь ты. Задача, начатая раньше, продолжается
  как была.
- **Своя модель**: моделью проекта может быть и **«Своя модель»** — Ollama на этом компьютере или на другом через туннель,
  который держишь ты (Пульт достаёт только адрес самого этого компьютера). «Настройки → Модели и ключи → Своя модель →
  **Проверить и включить»** спрашивает сервер, что у него есть: подходит модель, которая умеет инструменты и у которой задан
  контекст от 16 тыс. (`PARAMETER num_ctx` в её Modelfile), — длинный запрос Ollama режет молча, поэтому модель без него не
  берётся. Включённая — получает свою вкладку **«Ресурсы → Своя модель»** (карточка в «Настройках» ведёт туда же): модели
  Ollama по весам — исходник с размером и под ним копии с контекстом, которые держат те же веса (+0 ГБ); галочка —
  модель в выборе задачи, звезда — основная; у модели без заданного контекста — **«Сделать копию с 32 тыс.»**, Ollama
  делает её из тех же весов. Касание по модели: **«Выгрузить»** из видеопамяти, **«Удалить»** — с тем, сколько это
  освободит (ничего, пока её веса держит другая модель). **«Скачать модель»** по имени с ollama.com: сначала Пульт
  называет размер, сколько места останется и влезет ли она в видеокарту с контекстом 32 тыс., и не скачивает ту, после
  которой на диске останется меньше запаса (60 ГБ, у маленького диска — десятая часть); скачивает сама Ollama, ход виден
  во вкладке и на «Главной», а **«Остановить»** сохраняет скачанное до следующего раза. Вкладка при открытии сама
  спрашивает Ollama, так что новая модель видна сразу. Сколько места на диске сервера и что в видеокарте, Ollama не
  говорит: для этого рядом с ней ставится маленькая служба из `deploy/ollama-info/` (`sudo bash deploy/ollama-info/install.sh`,
  сокет systemd на 127.0.0.1:11436 — на запрос один JSON, в памяти ничего не держит), а её порт пробрасывается так же,
  как порт Ollama. В WSL показан диск C: Windows, на котором растёт диск Linux; освобождённое удалением место
  возвращается на C:, только если этот диск разреженный (sparse).
  Ключа не нужно: код не уходит из дома. Claude Code получает там пять инструментов — команды,
  чтение, правку и запись файлов, вопрос тебе, — и одна модель делает все роли; пока сервер не отвечает, задача не
  запускается. Собственная инструкция модели — SYSTEM в её Modelfile: роль, язык, меньше отказов — идёт с каждой задачей:
  Ollama её выбрасывает, когда запрос несёт свой системный промпт, а Claude Code несёт его всегда, поэтому её передаёт
  Пульт. **«Настройки модели»** (касание по модели во вкладке): системный промпт; длина контекста — от 16 до 256 тыс., у
  каждой — сколько видеокарты она займёт, по устройству самой модели (у gemma4 слои с окном делают длинный контекст
  дешёвым); температура, а под **«Тонкой настройкой»** — top_k, top_p, min_p, repeat_penalty и presence_penalty, незаданные в
  Modelfile — серые. Всё это пишется в саму модель, как это сделал бы `ollama create`, — она так же работает и вне Пульта;
  запросы Claude Code ничего из этого не несут, поэтому задача получает то, что в Modelfile. Модель до первой правки Пульт
  сохраняет копией `pult-was/…` (несколько строк, веса одни), и **«Вернуть как было до Пульта»** возвращает её. Две
  настройки — Пульта: **«Инструменты»** — пять основных или все инструменты Claude Code (от 64 тыс. контекста: одни их
  описания занимают ~22 тыс. токенов); **«После хода»** — держать модель в видеокарте или освобождать сразу (тогда
  следующий ответ ждёт загрузку модели). Системный промпт получает новая задача; начатая держит прежний. Пока на модели
  идёт задача, длина контекста не меняется. Выключить раздумья отсюда нельзя: Claude Code не просит «без раздумий», а
  Ollama у модели, которая умеет думать, включает их сама. Бесплатно, но слабее и медленнее Claude.
- **Какая модель что сделала**: каждая карточка называет свою модель — в «Идёт сейчас» справа в верхней строке
  («Opus 5.5», «DeepSeek · v4-pro»), у итога законченной задачи — внизу, напротив «Проверено», у вопроса и разрешения —
  перед тем, сколько ждёт, в строке законченной задачи — справа во второй строке; в сессии — у поля ввода.
- **Сколько Claude работал**: «работает 47 мин» в «Идёт сейчас» — вся работа над задачей, все её ходы без времени, пока
  она ждала тебя; на карточке «Твой ход» и наверху задачи те же часы стоят — серые, со знаком паузы, — пока не ответишь.
  Фоновая задача, оставленная после хода, в них не входит; ход, который начнёт её конец, — входит.
- **В фоне**: у «работает…» в сессии и на её карточке в «Идёт сейчас» — сколько помощников (агентов, которых Claude
  запускает сам) и команд идёт в фоне, с той секунды, как Claude их запустил, а не только после хода. Касание — каждый:
  у помощника тип, модель, сколько идёт, шаги и токены и что делает сейчас (из его собственной записи); у команды —
  процессор и память. В задаче, которую ведёт Пульт, **«Остановить»** прерывает её (спросит): это остановка самого
  Claude Code, и нового хода Claude из-за неё не начинает.
- **Скрин по ⌘V**: в «Что сделать», в строке сессии и в первой задаче нового проекта ⌘V (Ctrl+V на Windows и Linux)
  с картинкой в буфере прикладывает её, как кнопка «Картинка»; снимок сразу в буфер на Маке — ⌃⇧⌘4. Файл, перетащенный
  на поле, — так же; слова в буфере остаются словами, даже рядом с картинкой (так копируют Word, Excel и Numbers).
- **Сколько стоит задача производителя** — рядом со временем в шапке задачи, «≈ $0,04», у DeepSeek и Kimi: токены
  задачи по прайсу модели; касание говорит, сколько ушло на вход и на выход. Это оценка сверху: чтение из кэша посчитано
  как обычный вход, наценка часов пик неизвестна. GLM идёт по подписке, своя модель бесплатна — там цифры нет.
- **Второе мнение Codex**: под итогом сессии **«Второе мнение · Codex»** просит Codex — агента OpenAI, со входом в
  ChatGPT на твоём компьютере — прочитать, что изменила задача с начала (в git — всё с коммита, на котором стояла папка,
  и новые файлы; без git — файлы, которые писали правки Claude), вместе с твоим запросом и итогом Claude, чтобы
  сделанное нарочно не сочлось ошибкой. Он читает в песочнице только для чтения и ничего не спрашивает; по одному,
  обычно минута-две, **«Остановить»** прерывает. Замечания приходят карточкой в конце сессии, у каждого — место в
  проекте: касание открывает правку файла на этой строке (сам файл, если задача его не меняла); у каждого замечания галочка: сними — и оно
  останется здесь; кнопка говорит, сколько уйдёт, а следующей проверке этой задачи сказано его не повторять.
  **«Отправить Claude»** кладёт отмеченные в сессию твоим сообщением — кнопка
  называет того, кто делал задачу: на модели DeepSeek — **«Отправить DeepSeek»**, — а **«Проверено»** убирает карточку.
  Когда замечания ушли и задача ответила, кнопка под итогом становится **«Проверить исправления · Codex»**: Codex
  проходит по своим замечаниям и говорит про каждое — **«Исправлено»**, **«Осталось»** (и что ещё не так) или
  **«Нарочно»**, если исполнитель объяснил и Codex согласен, — и называет, что сломали сами исправления, если
  сломали; оставшееся уходит обратно одним касанием. Каждый круг начинается с твоего касания: сам Пульт одну модель
  на другую не запускает. **Задачу, которую сделал Codex, так же читает Claude** — **«Второе мнение · Claude»** под её
  итогом: Claude (Sonnet) по твоей подписке Claude, в сессии, у которой есть только инструменты чтения, так что изменить
  он ничего не может; замечания уходят Codex, исправления проверяет он же. Про такой проект Пульт тоже спрашивает один
  раз — его код тогда идёт в Anthropic. В первый раз в проекте Пульт спрашивает, можно ли отдать его код OpenAI; потом это
  видно на экране проекта, и **«Запретить»** забирает разрешение. Кнопка есть только там, где стоит Codex (он идёт с
  ChatGPT для Mac, или команда `codex`); версию Codex, на которой Пульт не проверен, он сначала сверяет с её
  собственным протоколом.

**Как найти задачу.** Строка вверху «Проектов» ищет по всем проектам, такая же на экране проекта — по нему: по названиям
задач, их первым запросам и тегам. Список «Раньше» в проекте продолжается кнопкой «Показать ещё 40». «Назад» возвращает
на то место экрана, где ты его оставил.

## В Telegram

У каждого проекта — своя тема в группе; туда приходят ходы, итоги, вопросы и запросы разрешений его сессий.

**Когда Telegram зовёт** (с приложением Telegram работает как пейджер — звонит только о том, что ждёт тебя):
о том, что закончилось, пока приложение было на экране, он зовёт через пять минут после ухода из приложения и только
если задача ещё ждёт; о вопросе или разрешении без ответа напоминает через 30 минут и через 2 часа; с 23:00 до 8:00
всё приходит без звука, кроме тревог безопасности; раз в день, в 9:00, одно сообщение в «Общей» подводит, что ждёт
тебя, по проектам. Все четыре настройки — в приложении: «Настройки → Уведомления».
Режим **«Компьютер»**, при котором Telegram молчит, сам кончается утром — в час, когда кончаются тихие часы, без них
в 8:00, — и снова «Авто»; до какого часа — видно в «Настройки → Уведомления».

| | |
|---|---|
| ответ на сообщение сессии | продолжить эту сессию |
| текст в теме | текущая сессия темы (🎯 в закреплённой карточке); нет её — единственная открытая, иначе Пульт спросит один раз |
| `/new текст` или `/new`, потом текст | новая сессия в этом проекте |
| файлы, снимки, альбом | лягут в `inbox/<дата>/` проекта под своими именами; файлы без слов ждут твоего следующего сообщения |
| голосовое | станет текстом (с бесплатным ключом Groq, `pult stt`); под ним тихая строка — что услышано |
| `/desk` `/phone` `/auto` `/mode` | где ты: тихо за компьютером, всегда со звуком или со звуком после 2 минут без тебя |
| `/status`, `/projects`, `/sessions` | что открыто сейчас; проекты; недавние сессии этого проекта |
| `/stop` | прервать текущую сессию темы, запущенную из Telegram |
| `/app`, 📱 Pult в закрепе темы | открыть веб-приложение |

Знаки в ленте: ⏳ работает · ✅ итог · ✔️ решено или готово · 🟠 ждёт тебя · ✋ разрешение · ❓ вопрос · ⚠️ сбой ·
⚙️ задача. Длинный итог показывает начало; остальное открывается касанием.

**Попросить у Claude файл.** Каждая сессия при старте узнаёт, что может прислать файлы своего проекта в его тему
командой `pult send ФАЙЛ… [-m ТЕКСТ]`; задаче Codex говорится то же, и команда работает в его песочнице. Только файлы
внутри проекта, до 50 МБ каждый, до десяти за раз, и ничего похожего на ключи и настройки (`.env`, `*.pem`, `.ssh/`,
`credentials*`).

**Звонит, только когда важно.** С веб-приложением Telegram становится пейджером: звонит, когда Claude ждёт тебя, а
тебя нет ни в приложении, ни за компьютером. Напоминания о долгих ходах; предупреждения на 80 % и 95 % лимита.

## В терминале

`pult help` перечислит всё: `status`, `setup`, `start|stop|restart`, `busy`, `hooks on|off`, `tab …`, `app`, `stt`,

## Безопасность и приватность

- **Кто может управлять компьютером:** только твой аккаунт Telegram (`PULT_ALLOWED_USER_IDS`) и только в привязанной
  группе. Тот, кто попадёт в твой Telegram, сможет запускать Claude Code с правами твоего пользователя: включи
  двухэтапную проверку.
- **Токен бота — это ключ.** Он лежит в `~/.config/pult/env` (права 600). Утёк — `/revoke` в @BotFather и
  `pult setup`.
- **Что уходит в Telegram:** твои запросы, ответы Claude, названия шагов, команды и имена файлов в запросах
  разрешений, вопросы и файлы, которые присылаешь ты или Claude. Telegram хранит это, как любой чат; чаты с ботами
  не шифруются сквозным шифрованием.
- **Посредник** ничего не хранит на диске и отсекает чужих по подписи Telegram и твоему ID; компьютер заново проверяет
  каждый вход токеном бота, который его не покидает. Страница выполняет скрипты только с твоего сервера и Telegram.
  Но кто управляет этим сервером, тот может действовать в Пульте от твоего имени: держи посредника на сервере, которому
  доверяешь, как своему компьютеру.
- **Тревоги** со звуком: вход в приложение из новой сети и признаки того, что токен бота есть у кого-то ещё;
  «Настройки → Безопасность» в приложении закрывают все окна. У ссылки, слова которой прячут адрес, виден домен.
- **Другие производители:** код проекта уходит в OpenAI только в проекте, моделью которого ты сделал Codex, — его задачи
  идут в песочнице на папку проекта, а выйти из неё он спрашивает, — или со вторым мнением, которое ты попросил, когда
  разрешил этот проект; ревью читает в песочнице только для чтения. И то и другое — с твоим входом в ChatGPT; ключей Пульта
  Codex не получает, а задача и ревью остаются в его истории, как любая твоя задача там. DeepSeek, GLM и Kimi видят проект
  только как его модель, по твоему ключу; своя модель через Ollama никуда ничего не шлёт.
- **Ключи производителей** лежат в `~/.config/pult/env`, как токен бота; приложение может положить или убрать ключ, но
  не прочитать его. Без ключа Claude Code отправил бы на адрес производителя твой вход в Claude — поэтому сессию
  производителя без ключа Пульт не запускает.
- **Никакой телеметрии.** Журналы остаются на компьютере. `pult report` печатает состояние без токенов, ID, имён
  папок и текста сообщений — для отчёта об ошибке. Уязвимости — [SECURITY.md](../SECURITY.md).

## Твои подписки и производители

У Пульта нет своего входа и своей модели. Он управляет агентами, которые уже установлены и вошли в аккаунт на твоём
компьютере, — с твоими аккаунтами и лимитами твоих подписок, так же, как ты сам.

- **Claude Code** — твой аккаунт Claude и подписка, как в терминале.
  [Документация Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) говорит: *«Unless previously approved,
  Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products,
  including agents built on the Claude Agent SDK»* (без согласования Anthropic не разрешает сторонним разработчикам
  предлагать в своих продуктах вход через claude.ai или его лимиты). Пульт вход не предлагает: он запускает за тебя
  твой собственный Claude Code. И всё же прочитай условия своей подписки и реши сам. Claude Code можно войти и с
  ключом API Anthropic; с Пультом так пока не проверялось.
- **Codex** — твой вход в ChatGPT, в собственной программе Codex; задача или ревью тратит долю окон Codex твоей подписки
  (карточка ревью говорит, сколько занято в окне на 5 часов).
- **DeepSeek, GLM, Kimi** — твой ключ у каждого, платишь им по их ценам. Подсказки Claude Code написаны под Claude, и
  Anthropic другие модели внутри него не поддерживает.
- **Своя модель** — Ollama на твоём компьютере или на другом твоём: бесплатно, и ничего никуда не уходит; слабее и
  медленнее Claude — для задач попроще.

Pult — независимый проект с открытым кодом, не связан с Anthropic, OpenAI или другими производителями, с которыми
работает, и не одобрен ими. Claude и Claude Code — товарные знаки Anthropic, Codex и ChatGPT — OpenAI; остальные
названия принадлежат их владельцам.
