# Как пользоваться Пультом

## В Telegram

У каждого проекта — своя тема в группе; туда приходят ходы, итоги, вопросы и запросы разрешений его сессий.

| | |
|---|---|
| ответ на сообщение сессии | продолжить эту сессию |
| текст в теме | текущая сессия темы (🎯 в закреплённой карточке); нет её — единственная открытая, иначе Пульт спросит один раз |
| `/new текст` или `/new`, потом текст | новая сессия в этом проекте |
| файлы, снимки, альбом | лягут в `inbox/<дата>/` проекта под своими именами; файлы без слов ждут твоего следующего сообщения |
| голосовое | станет текстом (с бесплатным ключом Groq, `pult stt`) |
| `/desk` `/phone` `/auto` `/mode` | где ты: тихо за компьютером, всегда со звуком или со звуком после 2 минут без тебя |
| `/status`, `/projects`, `/sessions` | что открыто сейчас; проекты; недавние сессии этого проекта |
| `/stop` | прервать текущую сессию темы, запущенную из Telegram |
| `/app`, 📱 Pult в закрепе темы | открыть веб-приложение |

Знаки в ленте: ⏳ работает · ✅ итог · ✔️ решено или готово · 🟠 ждёт тебя · ✋ разрешение · ❓ вопрос · ⚠️ сбой ·
⚙️ задача. Длинный итог показывает начало; остальное открывается касанием.

**Попросить у Claude файл.** Каждая сессия при старте узнаёт, что может прислать файлы своего проекта в его тему
командой `pult send ФАЙЛ… [-m ТЕКСТ]`. Только файлы внутри проекта, до 50 МБ каждый, до десяти за раз, и ничего
похожего на ключи и настройки (`.env`, `*.pem`, `.ssh/`, `credentials*`).

**Звонит, только когда важно.** С веб-приложением Telegram становится пейджером: звонит, когда Claude ждёт тебя, а
тебя нет ни в приложении, ни за компьютером. Напоминания о долгих ходах; предупреждения на 80 % и 95 % лимита.

## В веб-приложении

- **«Главная»** построена вокруг того, чей ход: что идёт сейчас (у каждой задачи — твой запрос и что Claude пишет
  прямо сейчас), ниже — что ждёт тебя: запросы разрешений с ответом прямо там и каждая закончившая сессия, с готовыми
  ответами из сообщения самого Claude, — и все проекты, каждый своим цветом. Законченная задача, даже простой отчёт,
  остаётся там, пока ты не нажмёшь **«Понятно»** (на карточке или под итогом в сессии) или не ответишь: открыть её —
  не значит убрать, так ничего законченного не проскочит непроверенным.
- **Закреплённые проекты**: сдвинь строку проекта влево на экране «Проекты» и нажми «Закрепить» — или кнопку с
  булавкой в шапке проекта. Закреплённые стоят сверху в «Проектах», на «Главной» и в списке новой задачи, новый — выше;
  остальные — как прежде, по тому, кому нужен ты. Закрепление хранит компьютер: на любом телефоне одно и то же.
  Под тем же сдвигом — **«Спрятать»**: проект уходит в свёрнутые «Скрытые» внизу «Проектов», с «Главной» и из списка новой
  задачи пропадает (что в нём идёт и что ждёт тебя, видно по-прежнему; сдвиг в «Скрытых» возвращает), — и **«Новая задача»**,
  сразу форма с этим проектом. Строка задачи сдвигается к **«Тегам»**, карточка «Твой ход» — к **«Понятно»**; вопросы и
  разрешения не сдвигаются.
- **Скопировать сообщение**: в сессии сдвинь его влево, пока не загорится значок копирования, и отпусти. Сообщение
  Claude целиком уходит в буфер с форматированием, как копирует сам Telegram, — вставка в Telegram, заметки или почту
  сохранит жирный, ссылки, код и цитаты, — и markdown Claude для мест, где только простой текст; твоё — как ты его
  написал. Нажатие на серый блок кода по-прежнему копирует только этот блок.
- **Второе мнение Codex**: под итогом сессии **«Второе мнение · Codex»** просит Codex — агента OpenAI, со входом в
  ChatGPT на твоём компьютере — прочитать, что изменила задача с начала (в git — всё с коммита, на котором стояла папка,
  и новые файлы; без git — файлы, которые писали правки Claude), вместе с твоим запросом и итогом Claude, чтобы
  сделанное нарочно не сочлось ошибкой. Он читает в песочнице только для чтения и ничего не спрашивает; по одному,
  обычно минута-две, **«Остановить»** прерывает. Замечания приходят карточкой в конце сессии, у каждого — место в
  проекте: касание открывает файл на этой строке; **«Отправить Claude»** кладёт их в сессию твоим сообщением,
  **«Понятно»** убирает карточку. В первый раз в проекте Пульт спрашивает, можно ли отдать его код OpenAI; потом это
  видно на экране проекта, и **«Запретить»** забирает разрешение. Кнопка есть только там, где стоит Codex (он идёт с
  ChatGPT для Mac, или команда `codex`); версию Codex, на которой Пульт не проверен, он сначала сверяет с её
  собственным протоколом.
- **Модели других производителей**: в «Новой задаче» над моделью — **«Кто делает»**: Claude, или DeepSeek, GLM, Kimi.
  Задачу на их модели ведёт сам Claude Code (они отвечают его же протоколом по своему адресу), по твоему ключу: ход,
  карточки, итог и тема — как с Claude, а в поле модели — модели этого производителя. Ключ кладёшь в «Настройки →
  Другие производители» — он проверяется одним крошечным запросом и остаётся на компьютере, — там же правишь список
  моделей: первая — главная, вторая — быстрая (заголовки, подагенты). Первый выбор в проекте спрашивает, можно ли отдавать
  его код другим производителям (то же разрешение, что у второго мнения); **«Сделать по умолчанию»** отправляет туда новые
  задачи проекта, и из Telegram тоже; «Настройки → Другие производители → **Кто делает новые задачи по умолчанию**» — сразу
  для всех разрешённых проектов (своё умолчание проекта важнее). Сессия остаётся у своего производителя при продолжении и копии, без ключа не
  запускается и в списке VS Code не видна. Anthropic этого не поддерживает, а подсказки Claude Code написаны под Claude:
  это для задач подешевле, не для сложных.
- **Сессия** — вся переписка вживую; у поля ввода — модель, раздумья и шкала контекста. Выбери модель (Fable, Opus,
  Sonnet, Haiku) и насколько глубоко Claude думает в этой сессии; идущая переключается сразу. «Настройки → Модель и
  раздумья» — с чем начинаются сессии из приложения и Telegram; вкладки VS Code — по своим настройкам.
- **Теги**: у каждой задачи два — раздел проекта и тема в нём; их ставит та же маленькая модель, что пишет строку
  итога, сразу по запросу и ещё раз в конце хода. Модель включается переключателем «Настройки → Строка итога простыми
  словами» (сначала он выключен). Папки и файлы — только подсказка ей: больше настраивать ничего не нужно. Нажми раздел
  наверху экрана проекта — останутся только его задачи (и ряд его тем); нажми теги под заголовком задачи — поправишь,
  и твой выбор останется. `#тема` в тексте запроса ставит её сразу — даже когда переключатель выключен. В Telegram итог
  хода заканчивается ими же — хештегами: `#прошивка #датчик_филамента`, нажмёшь — все сообщения с ним («Настройки →
  Хештеги в Telegram»). Значок тега рядом с разделами проекта открывает все его теги — самые ходовые наверху, у
  каждого число задач: переименовать раздел или тему, дать разделу цвет, слить два в один, скрыть (у задач тег
  остаётся, но в строках, фильтре и Telegram его не видно; вернуть — внизу экрана). Тег, который Claude только что
  придумал, обведён пунктиром, пока ты его не оставишь или не сольёшь с другим. Claude и сам просматривает список и
  предлагает слить два тега об одном и том же; «Оставить обе» — больше не предложит. Дальше Claude ставит твои
  названия: старое имя, если он его принесёт, ляжет на новый тег. Когда переключатель включён, при первом открытии
  проекта Claude сам раскладывает его прежние задачи без тегов (последние 200, по двадцать, в фоне; под разделами —
  «Claude раскладывает прежние задачи: 40 из 120») — один раз на проект. «Разложить заново» внизу экрана тегов сначала
  спросит, потом составит список с нуля — из README, CLAUDE.md, последних задач и твоих тегов — и разложит по нему все
  задачи, кроме тех, где тег ставил ты; около минуты. Каждый тег, который ты ставишь сам — в листе задачи, `#тегом`,
  слиянием, — пример для Claude: он видит шесть последних в проекте и так же раскладывает похожие задачи; «Claude ставит
  сам» в листе забирает пример обратно.
- **«Ресурсы»**: «Лимиты» — кривая каждого лимита против ровного темпа, прогноз (в темпе; недобор — сколько часов
  работы сессии сгорит; перебор — когда кончится), кто съел; «Компьютер» — процессор, память и команды каждой сессии
  Claude.
- **Файлы хода**: что Claude создал или изменил в проекте — отметь нужные и отправь в тему по одному или одним
  архивом; файлы прошлых ходов — в соседних.
- **Новый проект**: папка где угодно в домашней — пустая с git, с `CLAUDE.md`, который Claude напишет по твоему
  описанию, или клон репозитория. Тема проекта сразу появляется в группе.

- **Сам Пульт**: «Настройки → Пульт и его части» — компьютер, приложение и посредник на твоём сервере, копия на этом
  телефоне, вкладки VS Code, хуки, Claude Code и выпуск: что у каждой стоит и насколько отстало от ветки, из которой
  Пульт поставлен. Новый выпуск ставится оттуда одной кнопкой (macOS, Linux; клон сам находит выпуски на GitHub), сервер
  приложения берёт тот же с GitHub ([один раз: `install.sh --auto`](../deploy/relay/README.md#updates)). Версию Claude
  Code, которую скачал VS Code, Пульт проверяет на компьютере до того, как на неё перейдут вкладки; выключатель —
  «Проверять новые версии Claude Code».

## В терминале

`pult help` перечислит всё: `status`, `setup`, `start|stop|restart`, `busy`, `hooks on|off`, `tab …`, `app`, `stt`,
`send`, `run`, `report`, `uninstall`. `pult run -- npm run build` сообщает в Telegram о начале, ходе и коде выхода
долгой команды так же, как о ходах Claude.

## Безопасность и приватность

- **Кто может управлять компьютером:** только твой аккаунт Telegram (`PULT_ALLOWED_USER_IDS`) и только в привязанной
  группе. Тот, кто попадёт в твой Telegram, сможет запускать Claude Code с правами твоего пользователя: включи
  двухэтапную проверку.
- **Токен бота — это ключ.** Он лежит в `~/.config/pult/env` (права 600). Утёк — `/revoke` в @BotFather и
  `pult setup`.
- **Что уходит в Telegram:** твои запросы, ответы Claude, названия шагов, команды и имена файлов в запросах
  разрешений, вопросы и файлы, которые присылаешь ты или Claude. Telegram хранит это, как любой чат; чаты с ботами
  не шифруются сквозным шифрованием.
- **Посредник** ничего не хранит и отсекает чужих по подписи Telegram и твоему ID; компьютер заново проверяет
  каждый вход токеном бота, который его не покидает. Страница выполняет скрипты только с твоего сервера и Telegram.
- **Тревоги** со звуком: вход в приложение из новой сети и признаки того, что токен бота есть у кого-то ещё;
  «Настройки → Входы» в приложении закрывают все окна. У ссылки, слова которой прячут адрес, виден домен.
- **Другие производители:** код проекта уходит в OpenAI только со вторым мнением, которое ты попросил, и только когда
  ты разрешил этот проект. Codex читает в песочнице только для чтения, со своим входом в ChatGPT; ключей Пульта он не
  получает. Ревью остаётся в истории Codex, как любая твоя задача там.
- **Ключи производителей** лежат в `~/.config/pult/env`, как токен бота; приложение может положить или убрать ключ, но
  не прочитать его. Без ключа Claude Code отправил бы на адрес производителя твой вход в Claude — поэтому сессию
  производителя без ключа Пульт не запускает.
- **Никакой телеметрии.** Журналы остаются на компьютере. `pult report` печатает состояние без токенов, ID, имён
  папок и текста сообщений — для отчёта об ошибке. Уязвимости — [SECURITY.md](../SECURITY.md).

## Claude Code, твоя подписка и Anthropic

У Пульта нет своего входа и своей модели. Он управляет Claude Code, который уже установлен и вошёл в аккаунт на
твоём компьютере, — с твоим аккаунтом и лимитами твоей подписки, так же, как ты в терминале.
[Документация Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) говорит: *«Unless previously approved,
Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products,
including agents built on the Claude Agent SDK»* (без согласования Anthropic не разрешает сторонним разработчикам
предлагать в своих продуктах вход через claude.ai или его лимиты). Пульт вход не предлагает: он запускает за тебя
твой собственный Claude Code. И всё же прочитай условия своей подписки и реши сам. Claude Code можно войти и с
ключом API Anthropic; с Пультом так пока не проверялось.

Pult — независимый проект с открытым кодом, не связан с Anthropic и не одобрен ею. Claude и Claude Code —
товарные знаки Anthropic.
